## 1. 档次先分开

方向锁定之后再选一档，并在 `STATUS.md` 里改成已锁定。

| 档 | 判断 |
|----|------|
| CVPR / ICCV / NeurIPS 一作 | 默认不作为当前目标 |
| SCI 一区 / CCF-A | 周期长。只有题目和实验已经超过应用论文的要求时才考虑 |
| 正规 EI 会议或应用刊 | 题小、页数短时的默认候选。仍然要有问题、相关工作、可复现实验、基线、对照、局限 |
| 包录 / 假会 | 禁止 |

## 2. 投稿原则

1. 圈定会或刊之前不投稿。
2. 优先能在 IEEE Xplore、SPIE 或期刊官网核到的出处。
3. 录用后核：EI Compendex 是否真收录该届论文集，而不是官网写「提交 EI」。
4. 来不及冻结数字的截稿放弃，不空投。
5. 正文按 `PLAN.md` 第 2 节清单写全。模板页数不够时压缩句子，不删这些块。

不要投「保证检索、三天录用」的中介会。
