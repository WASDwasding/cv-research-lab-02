## 1. 阶段

日期不先排。每一阶段完成时要留下的文件先写在「完成时留下」。

| 阶段 | 状态 | 做什么 | 完成时留下 |
|------|------|--------|------------|
| 环境 | 未开始 | 最小训练跑完 | `experiments/00_env_check.md` 里的版本和验证准确率。该数字不进主表 |
| 定义 | 未开始 | 任务或标签规则写死 | `experiments/label_protocol.md` |
| 划分 + 基线 | 未开始 | 固定种子；朴素基线；至少一种正经模型 | 划分文件；`results/` 里的 CSV；Accuracy 或本题主指标 |
| 对照 + 消融 | 未开始 | 事先写明的对照和至少两个开关 | 主表；消融表 |
| 失败案例 | 未开始 | 按下面列好的类型导出错例 | 清单 CSV；图注里的类型 |
| 题外验证 | 未排 | 仅当方向文件要求 | 单独划分上的指标和掉点。不据此换模型 |
| 冻结 | 未开始 | 上表锁定后不再改测试集 | 正文数字与 CSV 逐格一致 |
| 成文投稿 | 未开始 | 清单内的表图进正文 | 回执 |

不上未写入方向文件的大模型，不把多个任务并进同一篇。数字冻结前不换测试集，也不投稿。

## 3. 指标与陷阱

**先用：** 待定。分类任务默认 Accuracy、macro-F1、混淆矩阵。有序标签再加有序误差。检测再加定位指标。

**失败类型（方向锁定后改成具体的）：** 待定。至少事先列出会误伤结论的几类，导出错例时不临时增删。

**坑：**

- 只报训练准确率，或测试集参与了选模
- 无基线，只说「用了某网络所以有效」
- 把不同机器上的数字合成同一张表
- 同时开多个互不相关的任务
- 为凑版面增加没有事先写下的实验

## 4. 机器约定

- **GPU 机器：** 主训练。记录 CPU、GPU、CUDA 版本。
- **笔记本：** 脚本、可视化和 CPU 冒烟。不存原始大数据集。
- **云 GPU：** 只有本地显存放不下时按次使用，并在实验记录里写明。

每次实验在 `experiments/YYYYMMDD_短名.md` 记录命令、超参、机器和结果路径。CSV 进 `results/`。文件名带日期和机器。
