# Yu、Wang 2024/2025：回收书表面缺陷

Jun Yu，WenJian Wang. DDNet: Deformable Convolution and Dense FPN for Surface Defect Detection in Recycled Books. arXiv:2409.04958，2024-09-08。会议版 ICASSP 2025。

## 问题

回收和再次流通的书，包括古籍和用过的课本，价值取决于表面保存状况。作者要检测并分类表面缺陷，不是输出一个新旧档。

## 数据

SHBD，6366 张，有训练、验证、测试划分。论文写支持分类、检测和语义分割。六类：

| 类 | 论文中的意思 |
|----|----------------|
| Vitium | 缺边、缺角或缺页 |
| Defaced | 水渍或油渍 |
| Crease | 折痕、裂，或书页折角 |
| Patch | 胶带或黏合修补 |
| Signature | 馆藏章或销售章 |
| Inkiness | 签名、笔记或其他墨迹 |

缺陷可以在封面或内页，一张图可以有多类。摘要写 “proprietary dataset”。2026-10-14 没有找到公开下载。

## 方法

在检测器上换了可变形卷积，并用密集连接的 FPN 融合多尺度特征。对照包括 YOLOv5。

## 论文里的数字

SHBD 上 mAP 46.7%，比所写基线高 14.2 个百分点。数据下不到，这个数不能复现，也不进本实验主表。

## 边界

类别里既有物理损伤（缺、污、折），也有印章和笔迹。印章不一定表示书更旧。古籍和现代课本混在同一个集里，论文没有按品类分开报告。

## 和本实验

类别表是目前看到的最完整的书表面缺陷清单。在作者放出数据之前，只能借用这张清单来对照我们以后要不要这些类，不能拿来训练。
