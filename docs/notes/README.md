# 文献笔记

这里记别人的论文、数据集和品相口径。2026-10-14 已定的范围和仍空着的细节在 `open-questions.md`。可参考的做法在 `methods.md`，还没有选定其中一种。别人论文里的数字不进本实验主表。

检索日期：2026-10-14。

## 先读（对象就是书的表面缺陷或二手书品相）

1. `2023-hong-used-books.md`。Hong、Jeong，CSSE 2023。图书馆书的损伤框，620 张，公开在 Roboflow。论文没有给出整书档位。
2. `2024-yu-ddnet.md`。Yu、Wang，ICASSP 2025 / arXiv:2409.04958。回收书表面缺陷，SHBD 6366 张。摘要写的是自有数据，没有找到公开下载。
3. `2024-tomas-book-defects.md`。Tomas 等，WCSE 2024。个人藏书，531 张，10 类缺陷。作者把「再合成 Like New / Good 这类档位」写成以后的工作。检测 mAP 约 0.07–0.11。

## 口径（不是数据集，也还没选用）

`standards.md`。AbeBooks / ABAA 的 Fine、Very Good、Good，中文旧书的十品到六品，多抓鱼的全新 / 良品 / 中品。这些只说明市面上有哪些说法。

## 数据集一览

`datasets.md`。能下的、不能下的、以及看起来像书但任务不是品相的，分开写。

## 相邻工作（页纸退化、修复、版面，不是整书品相）

4. `2019-kim-foxing.md`。旧书页上的褐斑面积，颜色统计，不是公开数据集。
5. `2021-arnia-dcnet.md`。古籍图像块的退化类型分类。数据来自 DIBCO、PHIBD 和私有 Jawi，标签是退化类型，不是品相档。
6. `2025-ivanova-artefact.md`。多种实体媒介的损伤分割，里面有少量书封。公开。
7. `adjacent.md`。历史文献修复、古籍版面、污渍去除、一个未发论文的中古书分级演示。读的时候不要把它们的指标当成品相指标。

## 做法

`methods.md`。四种做法都对着已定的范围写：使用品相、多视角、分档再估价、实体书不限种类。档的名称和价格公式还没定，所以四种都还不是本实验的方法。
