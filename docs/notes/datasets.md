## 页纸或文物损伤，任务不是整书品相

| 名称 | 什么时候才值得下 | 为什么现在不下 |
|------|------------------|----------------|
| DIBCO 2009–2018、PHIBD | 若题目收成「一页纸属于哪类退化」 | 标签是透背、污斑、对比度低等，服务的是二值化，不是二手书档位 |
| ARTeFACT | 若要像素级损伤，且接受书只是其中一种媒介 | 418 张高分辨率图，15 类损伤，含书封但主体是画、照片、织物等。https://daniela997.github.io/ARTeFACT/ |
| HDR28K | 若题目是把受损页面修回原貌 | 28552 对受损–修复图，损伤是合成的。https://github.com/yeungchenwa/HDR |
| StainDoc | 若题目是去掉文档污渍 | 约 5000 对污渍图，污渍是造出来的，任务是去除 |
| 褐斑合成集（Zenodo，2026） | 若只要褐斑和虫粪的框 | 历史纸张上的生物性污损，不是流通二手书。https://zenodo.org/records/21602151 |
| SCUT-CAB | 若要中文古籍版面 | 4000 张，标签是版面元素。破损只是图像质量的一种情况，没有品相档 |

Kim 等 2019 的褐斑测量用的是首尔大学珍本库照片，软件叫 PicMan，没有放出数据集。
