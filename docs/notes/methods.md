# 可参考的做法

还没有选定。下面四种都接受已经定下的范围：看使用品相，输入是多张固定角度的照片，输出是档，再结合原价等给出估价，对象不限于一种实体书。

档的名称和价格公式见 `open-questions.md`，这里不填。

共同的拆法：图像只负责品相和可见缺陷。原价和其他非图像字段另走一条，不让网络去「猜定价」。估价在档和这些字段都有了之后才算。某个角度的图缺失时，结果里要写明缺了哪一张，而不是静默当成完好。

## 1. 每个角度检测缺陷，再用书面规则收成档

封面、封底、书脊、内页各自检测磨损、污渍、折角、笔迹、缺页。一张书面规则按缺陷的种类和大小收成整书的档。估价再用档和原价等计算。

文献里最接近的是缺陷检测，不是档：Hong、Jeong 2023（620 张图书馆书，Roboflow 可下，论文六类和网页五类不一致）；Yu、Wang 的 SHBD（6366 张，下不到）；Tomas 等 2024（531 张，十类，mAP 约 0.07–0.11，作者把打档留到以后）。

这条做法的结果能向另一个项目解释「为什么是这个档」。它依赖规则本身写得清楚。现有公开框不能覆盖全部实体书，古籍、精装、平装的缺陷样子不一样。

## 2. 多张图一起做有序分类

把一次拍摄的多张图看成一个样本，直接预测有序档位：把相邻档判错的代价小于把差很多档判错。估价仍是档之后的第二步。

这条做法和「要一个档」对齐。它需要的标签是整书的档，不是缺陷框。这样的公开集现在没有，得自己标。实体书不限种类时，同一档名在平装和线装上可能不是同一种伤，标注规则要写明这一点，否则模型学到的是书的种类而不是新旧。

## 3. 先认出书的装帧，再评品相

对象既然是所有实体书，装帧会差很远。ARTeFACT 在多种实体媒介上的结果是：一个损伤分割模型换一种材料就会漏或多分。

可以先把装帧分成少数几类（例如平装、精装、线装、其他），把装帧和图像一起送进品相模型，或者每一类装帧一个品相模型。装帧分类错了，品相也会错，所以装帧要单独报准确率。这不是把题目收窄成某一种书。

## 4. 用视觉语言模型按书面规则打档

把多张图和一份写死的档位说明一起交给视觉语言模型，让它返回档和依据。https://github.com/hyeminLee-project/used_book_grading 就是四张图加模型接口，输出四级，没有固定测试划分。

这条做法最快能在另一个项目里跑起来，但档会随提示词和模型版本变。论文若走这条，要锁模型版本、锁提示词、在固定测试集上和大类基线比，并且把接口失败当成失败案例。没有网络或没有接口时它不能用，所以不能当作唯一的可运行版本。

## 和另一个项目的衔接

调用入口是 `src/estimate.py`。它现在检查照片和原价是否给到，并返回档、缺陷和估价三个空位。空位是因为模型和公式都还没有，不把原价原样当成估价。选定上面某一种做法之后，只替换这三个空位的算法，不改调用方式。
