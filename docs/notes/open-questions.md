# 已定和未定

2026-10-14 定下来的只有范围。档叫什么、价格怎么算，仍然空着。

## 已定

| 项 | 决定 |
|----|------|
| 新旧指什么 | 使用后的品相：磨损、污渍、折角、笔迹、缺页。纸张年代上的旧不是主目标 |
| 输入 | 固定的多个角度，不是只看一张封面 |
| 输出 | 先分档，再结合这本书的原价等，给出估价 |
| 对象 | 实体书。不先收成现代平装，也不先收成古籍 |

## 还空着

1. 档有几档、每档叫什么。`standards.md` 里的十品、AbeBooks、多抓鱼都还没选用。
2. 必拍的角度名单。封面、封底、书脊、切口、内页里，哪些缺了就不能估。
3. 原价从哪里来。用户输入、ISBN 查询，还是另一个项目已经有这个字段。
4. 「原价等」里的「等」还有哪些字段。没点名的因素不写进公式。
5. 论文的主结果是品相档，还是连估价一起评。估价依赖原价，原价不是从图像里看出来的。

这些空着的项不妨碍先看 `methods.md`。选定做法之前不下载主数据，也不把某一篇的类别表抄成我们的标签。
