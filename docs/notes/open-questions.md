# 已定和未定

2026-10-16 把评价界限锁定到 `experiments/label_protocol.md`。同日选定做法和必拍，写在该文件第 6 节。

## 已定

| 项 | 决定 |
|----|------|
| 新旧指什么 | 使用痕迹：磨损、污渍、折角、笔迹、缺页。明显发黄至少降到轻微使用 |
| 输入 | 六张：封面、封底、书脊、前部、正中、后部各一处展开。缺一张不给档 |
| 输出 | 四档之一，再按底数乘系数估价 |
| 对象 | 实体书，按册。平装、精装、线装都评。装帧不另记 |
| 档 | A 接近全新，B 轻微使用，C 明显使用，D 不建议流通。取最重的一条 |
| 标注 | 每本书只记书号和档。角度写在文件名里 |
| 做法 | 六张图一起做有序分类。微调已有图像模型，不从零训练 |
| 数据 | 20 本核对，不进训练和测试。之后 120 本训练、40 本测试。主数据自己拍 |
| 价格底数 | 有市场参考价用参考价，否则用定价。D 档、缺图、没有底数时不给价 |
| 论文主指标 | 档的准确率、macro-F1、混淆矩阵和有序误差。价格误差不进主表 |
