# 具体跑实验

每次实验一个文件，写清命令、数据、种子、机器和 `results/` 里的结果路径。

评价界限和做法在 `label_protocol.md`。主做法是六张图的有序分类。20 本核对集拍完、阈值不再改之前，这里不记书籍训练。

## 机器

两台电脑都用这个仓库，数字按机器分开记。

| 机器 | 用来做什么 |
|------|------------|
| 4060 游戏本 | 训练和评测。数据集放这台，不进 git |
| MacBook | 在外写代码和文档。不在这台跑主实验，也不存放原始大数据 |

同一张表里不混两台机器的数字。文件名带日期和机器，例如 `20261014_baseline_4060.csv`。4060 上的 CUDA、驱动和 `torch` 版本，等第一次环境检查时写进当天的实验记录，现在还没有测。
